# AI-Accelerator-MAC-Unit

## Project Overview
This project implements a 4-bit MAC (Multiply-Accumulate) Unit using Verilog HDL for AI accelerator applications.
The design performs multiplication and accumulation operations synchronously using clock-based sequential logic.

## Features
- 4-bit MAC architecture
- Verilog HDL implementation
- Testbench verification
- Simulation output analysis
- RTL design methodology

## Tools Used
- Verilog HDL
- RTL Design
- Jdoodle / EDA Playground

## Future Scope
- Systolic Array Design
- FPGA Implementation
- Low-power AI Accelerator Design
